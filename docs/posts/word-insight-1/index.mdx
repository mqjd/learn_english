## 单词辨析 competence compete

### 词源拆解

`compete`（竞争）与 `competence`（能力/胜任力）均源自拉丁语复合动词 **competere**：

- **前缀 `com-`**（together，共同） + **词根 `petere`**（to seek, strive after，奔向、寻求、争取）
- **字面本义**：“共同奔向 / 汇聚到一处”

在语言演变中分化为两个方向：
- **向外争夺**：大家一同争抢同一个稀缺目标 → 引申为 **compete**（竞争、对抗）。
- **向内汇聚**：各项条件与要求汇聚契合、符合标准 → 引申为 **competence**（胜任能力、资质）。

---

### 快速记忆

> 💡 **核心口诀**：  
> **只有具备足够的 competence（能力），才有资格去 compete（竞争）。**

- **Competence（能力）** 是你的**入场券**（自身条件是否达标）；
- **Compete（竞争）** 是入场后的**赛场较量**（与对手同台角逐）。

### 词族对比与高频搭配

| 单词 / 词性 | 核心释义 | 常见搭配与例句 |
| :--- | :--- | :--- |
| **compete** *(v.)* | 竞争、对抗、参加比赛 | • **compete with / against** sb.（与某人竞争）<br />• **compete for** sth.（争夺某物）<br />*例：Over 200 companies are competing for the contract.* |
| **competition** *(n.)* | 竞争；比赛、赛事 | • **fierce / stiff competition**（激烈的竞争）<br />• enter a competition（参加比赛）<br />*例：Fierce competition has driven prices down.* |
| **competitive** *(adj.)* | 竞争激烈的；好胜的；有竞争力的 | • **competitive edge / advantage**（竞争优势）<br />• competitive salary（有竞争力的薪水）<br />*例：She has a highly competitive nature.* |
| **competitor** *(n.)* | 竞争者、参赛者、同行对手 | • main / major competitor（主要竞争对手）<br />*例：The company bought out its chief competitor.* |
| **competence** *(n.)* | 胜任力、能力、法定权限 | • **core competence**（核心能力/胜任力）<br />• linguistic / professional competence（语言/专业能力）<br />*例：He demonstrated exceptional competence in project management.* |
| **competency** *(n.)* | （常用于职场）具体能力项、技能要求 | • **competency model**（胜任力模型）<br />*例：Problem-solving is one of the key competencies we look for.* |
| **competent** *(adj.)* | 胜任的、有能力的、合格的 | • **be competent to do sth. / in sth.**（能胜任某事）<br />*例：She is highly competent in financial analysis.* |
| **incompetent** *(adj.)* | 不称职的、不能胜任的、无能的 | • an incompetent manager（不称职的经理）<br />*例：The project failed because of incompetent leadership.* |
